A responsive and user-friendly website showcasing the traditional food, culinary culture, and popular eateries in Muar, Johor.

## Tech Stack
- **HTML5** - Structure and semantic content
- **CSS3** - Styling, layouts, and responsive design
- **JavaScript** - Interactive elements and dynamic user experience

##  Key Features
- Responsive design tailored for both mobile and desktop views
- Detailed guides and media galleries for iconic Muar dishes
- Clean and intuitive user interface
